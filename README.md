\# KI App Gap Analyst



Eine kostenlose KI-App, die App-Ideen analysiert und fehlende Features identifiziert.



\## Funktionen



\- Analyse von App-Ideen

\- Identifikation von Zielgruppe und Kernproblem

\- Wettbewerbs- und Feature-Gap-Analyse

\- MVP-Vorschlag mit maximal fünf Features

\- Risikobewertung



\## Tech-Stack



\- Python

\- Streamlit

\- Google Gemini API

\- python-dotenv
